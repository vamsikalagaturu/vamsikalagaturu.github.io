# vamsi.sh

Personal site of Vamsi Kalagaturu — [vamsi.sh](https://vamsi.sh)

Static HTML + CSS, built with Vite, deployed to GitHub Pages on push to `main`.
The page renders without JavaScript.

```sh
npm install
npm run dev      # local dev
npm run build    # -> dist/
```

See [CLAUDE.md](CLAUDE.md) for the design brief and content rules.
